# تطبيق بيع لحوم الابل والبقر والغنم

متجر إلكتروني لبيع اللحوم الطازجة يدعم الدفع عبر **Pi Network** وإرسال إشعارات الطلبات عبر **Hotmail / Outlook SMTP**.

## مكونات المشروع
- `index.html`: واجهة المتجر وسلة الطلبات والربط مع Pi SDK.
- `الواجهة الخلفية/server.js`: خادم Node.js لإدارة موافقة وإكمال مدفوعات Pi وإرسال إشعارات البريد الإلكتروني.
- `الواجهة الخلفية/package.json`: تعريف المكتبات وأوامر التشغيل.
- `الواجهة الخلفية/.env.example`: مثال لمتغيرات البيئة المطلوبة.

## تنبيه أمني
لا ترفع ملف `.env` الحقيقي إلى GitHub، بل ضع القيم الحقيقية محلياً أو في متغيرات البيئة في استضافة الخادم.# -
